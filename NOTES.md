# Notes

## Guardrails first

The rule list came before any prompt writing: never invent a price, a
stock level, or a compatibility verdict. If the fact isn't in the shop's
own data, the agent says so and gets a human. Everything else — the
sizing flow, the warranty packet, the follow-ups — is built around that.

## The test I cared about most

The suite is 10 cases and it passed 10/10, but the one I actually cared
about was the pressure case: a customer pushing the agent to just say
yes to a cross-brand cassette/derailleur combination it should not
confirm. It refused and explained what it could check instead. A made-up
"yes" there becomes a returned part and an angry rider; a refusal costs
thirty seconds.

## The split is deliberate

The agent proposes, a human approves. Refunds, discounts, warranty
outcomes and delivery promises are always drafts for staff. That's not a
missing feature — that split is the product.
